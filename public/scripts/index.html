06 / THE DETAILS

Questions,
answered.

A few things to know about purchases, compatibility, access, and future releases.

Do scripts keep working after every game update?+

Not necessarily. Third-party game and client updates can change compatibility. These tools are not guaranteed to work forever. Use of third-party scripts may violate platform rules and can put accounts at risk.

Can I view the raw code before buying?+

The public website shows explanations and non-functional UI previews only. The real Lua files stay outside the public website and are served only through authorized backend routes after payment confirmation.

Do STR and END work in Class B or Class C?+

No, not currently. Both are designed for Class A. Class B and C support is planned but isn't included in the current purchase.

How do I access my purchase?+

Log in to the account used during checkout and open My Library. Access requires a verified Stripe purchase and your newest personal loadstring. New installation approvals may require a short code in My Library. Public sales remain restricted while products are being verified.

Does auto-execute need activation every time?+

No. Approve the installation once using the code displayed on the first unapproved run. After that, the personal command can launch with main or alt accounts on that approved installation, including through your executor’s supported auto-execute feature. The executor must preserve the local installation identity file. Purchase validity and game/client compatibility still apply.

Why does My Library show a key replacement limit?+

The limit applies only to generating DIFFERENT personal keys, not your ownership or normal use. Use View my loadstring to retrieve your current command without paying, rotating, or using another activation code. Owners of older hashed-only keys can use Recover purchased loadstring once to enable permanent retrieval while preserving their approved installation.

Where is my activation code?+

Your 10-character installation code is logged to the Roblox F9 Developer Console’s Client tab when supported, and to your executor console/output after you run the newest personal loadstring from My Library. A small in-game activation panel with a Copy Code button is also displayed when supported; closing that panel does not close Roblox. Enter the code on the same signed-in library page within 10 minutes, approve it, and run that same command again. Do not regenerate an existing working loader to look for a code: a replacement revokes the previous key.

Are the executor stores officially partnered with BL Scripts?+

No. The websites listed under Need an executor? are third-party destinations, not official partners, verified resellers, or compatibility recommendations from Zebra's Shop. Your script purchase does not include an executor. Only install software you have independently researched and trust.

Can purchased code be copied or redistributed?+

No client-side code can be made impossible to copy after it is delivered. Secure access, licensing and obfuscation can make casual redistribution more difficult, but they cannot guarantee absolute protection.

Need help with an order or a product?

Reach Zebra's Shop directly by email, or browse answers in our Support Center. Never share card details or sign-in codes.
